## Render іске қосу дайындығы · 2026-10-17

`render.yaml` қосылды. YAML оқылуы, тегін тарифтер, базаға сілтеме, бір аймақ, жабық public DB access және same-origin web параметрлері жергілікті тексерілді. Web export қайта жиналды. Шаблондағы нақты start command бөлек тест PostgreSQL базасымен production режимінде іске қосылды: миграция, database-backed health, HTML/JS және deep link, бөгде Origin-ді қабылдамау, тіркелу, Secure/HttpOnly cookie, авторизацияланған API және logout өтті.

Бұл жергілікті HTTP тексеруі; Render аккаунтында ресурстар құру, провайдердегі build және сыртқы HTTPS мекенжайын тексеру әлі орындалған жоқ. Оларды Render арқылы орналастырғаннан кейін тексеру керек. Бастапқы 39 тест пен 5 Chromium сценарийінің нәтижелері төменде көрсетілген; бұл configuration/docs өзгерісінде олар қайта орындалмады.

## Түзетілген қателер

- Демо тапсырма тұрақты ID арқылы таңдалады: ретін ауыстыру және басқа тапсырманы өшіру оны бұзбайды.
- Live тапсырманың жаңа option/pair/element ID-лерін сервер тағайындайды; дұрыс жауап сілтемелері сақталады, басқа тапсырмалардың ID-лерімен қақтығыс жоқ.
- Ойын атауын өңдегеннен кейін демода бір тапсырманы қайта құрастыру жұмыс істейді; өңделген атау сақталады.
- Кіру, тіркелу және шығу session cache-ті нақты auth жауабымен жаңартады; бұрынғы аккаунт деректері мен кешіккен session fetch жаңа аккаунтты алмастырмайды.
- Басқа экраннан оралғанда таймер өткен уақытты сақтайды; клиент/сервер сағатының айырмасы ескеріледі.
- Бір start key-мен қатар келген join/retry сұраныстары бір ғана әрекетті жасайды. Retry басқа ойынның әрекетін немесе бастапқы аяқталған әрекетті қайтара алмайды.
- Демо үлгісінде жоқ қолмен қосылған тапсырманы қайта құрастыру батырмасы қолжетімсіз; оны автор өзі толтырады.

Браузерде мұғалімнің тіркелу → генерация → редактор → preview → сақтау → жариялау → қонақ орындауы → retry → аналитика жолы тексерілді. Орысша интерфейс, API қатесінде мәтінді сақтау, үш ойын механикасы, атауы өзгерген/реті ауыстырылған демоны қайта құрастыру, logout және таймермен экранға қайта оралу да тексерілді.

## API тесттері үшін бөлек PostgreSQL

Тесттер жазбалар жасайды. Жұмыс немесе мектеп деректерінің базасын қолданбаңыз. README-дегі жергілікті база қосулы болса:

```bash
docker compose exec db createdb -U oquplay oquplay_test
```

Бұл бір рет қажет; база бар болса қайта жасамаңыз. macOS/Linux терминалында, жоба түбірінде:

```bash
export DATABASE_URL=postgresql://oquplay:local_only@localhost:5432/oquplay_test
export TEST_DATABASE_URL=$DATABASE_URL
export WEB_ORIGIN=http://localhost:3001
export LLM_MODE=demo
npm run db:migrate
npm test
```

Windows PowerShell-де сол мәндерді `$env:DATABASE_URL`, `$env:TEST_DATABASE_URL`, `$env:WEB_ORIGIN`, `$env:LLM_MODE` арқылы орнатыңыз. Күтілетін нәтиже: **51 passed**. TEST_DATABASE_URL берілмесе API тесті әдейі тоқтайды. Қалыпты демо жұмысқа қайтқанда тест environment мәндерін алып тастаңыз немесе жаңа терминал ашыңыз.

## Браузер тесттері

Миграцияланған тест базасы бар терминалда:

```bash
npm run build:web
npm run preview
```

Серверді ашық қалдырып, басқа терминалда:

```bash
npx playwright install chromium
npm run test:e2e
```

Жиынтықта **8 сценарий** бар: бұрынғы 5 толық ойын сценарийі және сабақ студиясының 3 сценарийі. Соңғы үшеуінде ақылы генерацияның HTTP шекарасы басқарылатын fixture-мен алмастырылған; UI, нақты авторизация, ойын редакторы, файл жүктеу, слайдтан нақты видео жазу/декодтау және бас тарту браузерде тексеріледі. Сабақтың шынайы API/база сақтау жолы бөлек integration тестте тексеріледі.

Linux жүйелік кітапханалары қажет болса `npx playwright install --with-deps chromium` қолданыңыз. `E2E_BASE_URL` preview origin-мен сәйкес болсын. Дайын Chromium үшін `CHROMIUM_EXECUTABLE_PATH` қолжетімді. Қате болса `test-results` ішіндегі trace сол орындалуға тиесілі болады; ол тест мәтінін қамтуы мүмкін, оны production деректерімен жасамаңыз.

## Осы cloud ортадағы Prisma

Бұл орта `binaries.prisma.sh` жүктеуін proxy деңгейінде бұғаттайды. TLS немесе checksum тексеруі өшірілген жоқ. Оның орнына ресми `prisma/prisma-engines` репозиторийінің дәл `0edf323efd1d98336f3f0a68684b56f689b900d3` commit-інен шынайы schema-engine жиналды: Rust 1.97.1, өзгермеген Cargo.lock, Cargo checksum тексерулері. Native binary нұсқасы сол commit-ке сәйкес, динамикалық кітапханалары түгел табылды.

Cloud setup нұсқаулығы осы сақталған binary-ді штаттық `PRISMA_SCHEMA_ENGINE_BINARY` айнымалысы арқылы қолданады. Кәдімгі жергілікті ортада және CI-де Prisma-ның қалыпты ресми жүктеуі қолданылады; жоба Rust орнатуды талап етпейді.
