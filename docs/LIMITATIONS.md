# Белгілі шектеулер және кейінгі даму

## Осы нұсқаның шекарасы

- ЖИ сабақ студиясы тақырыптан материал, тапсырмалар, үй тапсырмасы және слайдтар жасайды. Web-та PPTX, Markdown және слайдтан дыбыссыз видео экспорты бар. Интернеттен дереккөз іздеу, диктор дауысы және генеративті бейне әлі қосылмаған. Қосылу жолы: [AI_LESSONS.md](AI_LESSONS.md).

- Нақты OpenAI кілтімен end-to-end генерация іске қосылмады. HTTP адаптері және validation логикасы тестпен тексерілген; нақты модельді таңдаған соң шағын материалмен smoke test қажет.
- iOS/Android JS және Hermes export бар, бірақ APK/IPA signing, орнату, Expo Go-да құрылғы сынағы, Safari, VoiceOver және TalkBack нақты құрылғыда тексерілмеген.
- Демо дайын 5 тапсырмамен, 6-сынып дүниежүзі тарихы және A деңгейімен шектелген. Демо режиміндегі қайта генерация дайын үлгіні қайтарады; шынайы жаңа нұсқа емес. Live-та 5/10/15 және A/B/C параметрлері сұралады.
- Құрылым және evidence үзіндісі тексеріледі. Мазмұнның тарихи/ғылыми дұрыстығы, age appropriateness, тіл тазалығы және ойлау деңгейі автоматты тексерумен толық кепілденбейді. Автордың тексеруі осы себепті бар.
- Редактор тек жарамды ойынды серверге сақтайды. Бос қосылған тапсырманы алдымен толтыру немесе өшіру керек. Жарамсыз аралық draft серверге autosave жасалмайды.
- Генерация/API қатесі сол экрандағы мәтінді сақтайды. Бетті толық жаңарту/қосымшаны жабу сақталмаған мәтінді жоғалтады. Офлайн режим мен autosave кейін қосылады.
- Қонақ сессиясы 7 күнге созылады. Cookie өшірілсе, браузер/құрылғы ауысса немесе аккаунтқа ауысса, бұрынғы қонақ тарихын біріктіру жоқ. Retry бір сессияда бір қатысушы болып есептеледі.
- Аккаунтқа туған күн, мекенжай, мектеп, сынып тізімі сұралмайды. Пошта растауы, парольді қалпына келтіру және өзіндік account deletion интерфейсі әлі жоқ. Бұл кең қоғамдық тіркелуге дайын толық authentication өнімінің орнына жүрмейді.
- Library тізімі ең соңғы 500 ойынды, сабақ студиясы 50 сабақты, жеке history 200 нәтижені көрсетеді. Үлкен көлемге pagination және архивтен қалпына келтіру қажет.
- Таймерге 5 секунд желілік жеңілдік бар. Офлайн соңғы жауаптарды серверге уақытында жеткізу кепілденбейді.
- Генерация job HTTP request ішінде орындалады. Процесс істен шықса RUNNING job жалғаспайды; ең кемі 3 минуттан немесе екі provider timeout пен 10 секунд өткен соң interrupted қатесі көрсетіледі. Durable background queue және серверлік cancellation кейінгі жұмыс.
- Request count/input/output лимиттері нақты валютадағы budget cap емес. Провайдердің өз бюджет шегін де орнату қажет.
- Rate limit бір процесс жадында, proxy конфигурациясы production алдында нақтыланады. DB quota ортақ. Үлкен жүктеме/replica тесттері жасалмаған.
- Сынып бөлісу коды қолында бар кез келген адам қонақ болып кіре алады. Қоғамдық каталог жоқ, бірақ сынып мүшелерін жеке тексеру де жоқ.
- Жабу жаңа кіруді тоқтатады. Бұрын басталған әрекет аяқталып, нәтижесін сақтай алады.
- HTTPS universal links/app links, push notifications, store signing және App Store/Google Play жариялауы қосылмаған.

## Келесі кезек

1. Нақты провайдер кілтімен 5/10/15 тапсырманың бағасы, жылдамдығы, қазақша және орысша сапасын сынау; live regression fixtures жинау.
2. Android/iPhone құрылғы тесттері, ең кішкентай экран, экран оқитын құралдар және фондағы таймер.
3. PostgreSQL серверінде үлкен параллель request/load сынағы, HTTPS орта және backup restore. Негізгі API және екі қатар join/submit/retry сұранысы PostgreSQL 17.11 серверінде тексерілді.
4. Draft autosave, pagination, account recovery/deletion, қауіпсіз пайдаланушының өз деректерін экспорттауы.
5. PDF мәтінін алу және OCR: файл көлемі, құпиялылық, page-level evidence және өңдеу кезегі.
6. Қосымша ойын шаблондары: бос орын, категориялау, карта/хронология. Әрқайсысына бөлек схема және серверлік grading.
7. Ақылы тарифтер: төлем провайдері, нақты token metering, billing webhooks және server-enforced quotas. Қазір төлем жоқ.
8. Дыбыстау, генеративті видео, серверлік фондық рендер және көпойыншы режим — келесі өнім кезеңдері. Қазіргі видео браузерде слайдтарды жазумен шектелген.
