# Тақырыптан ЖИ сабағын жасау

«ЖИ сабақ студиясы» бөлімінде тақырып пен сыныпты таңдаңыз. Дайын оқулық мәтінін енгізу міндетті емес. Қажет болса қосымша баптауларда пәнді, тапсырма түрін, санын және A/B/C деңгейін таңдаңыз. Пән бос болса, ЖИ оны тақырыпқа қарай анықтайды.

Сабаққа оқу мақсаттары, түсіндірмелер мен қолдану мысалдары, ұғымдар сөздігі, үй тапсырмасы, интерактивті ойын және 4–8 слайд кіреді. Материал аккаунтта сақталады. «Ойын редакторын ашу» арқылы тапсырмаларды өзгертіп, тексеріп, оқушыларға кодпен жариялауға болады. Оқушы аккаунтының сабақтары мен ойындары жеке қалады.

## Render-де нақты ЖИ-ді қосу

Алдымен жаңа кодты орналастырыңыз: Render → веб-сервис **oquplay** → **Manual Deploy → Deploy latest commit**. Жаңа migration іске қосылғанын және қызметтің **Live** болғанын тексеріңіз.

Одан кейін сол сервистегі **Environment → Add Environment Variable** арқылы:

| Айнымалы | Мәні |
| --- | --- |
| `LLM_MODE` | `live` |
| `LLM_API_KEY` | OpenAI API кілтіңіз; тек Render-дің құпия мән өрісіне енгізіңіз |
| `LLM_MODEL` | Аккаунтыңызда қолжетімді, Responses API + Structured Outputs қолдайтын модельдің нақты ID-і, мысалы `gpt-4.1-mini` (қолжетімді болса) |
| `LLM_TIMEOUT_MS` | `90000` |

**Save, rebuild, and deploy** немесе **Save and deploy** таңдаңыз. Кілтті GitHub-қа, скриншотқа немесе чатқа қоспаңыз. Сайтта «ЖИ қосулы» белгісі көрінген соң бір шағын тақырыппен, 5 тапсырмамен бастаңыз. API кілті мен модель берілмесе live сервер әдейі іске қосылмайды.

Render-дегі осы web нұсқа үшін `EXPO_PUBLIC_API_URL` айнымалысын қоспаңыз. Егер онда URL емес кездейсоқ мән тұрса, сол жолды өшіріп, **Save, rebuild, and deploy** таңдаңыз. Web және API бір мекенжайда тұрады; frontend-ке басқа API адресі қажет емес. Бұл native мобильді build үшін қойылатын толық HTTPS API адресінен бөлек баптау.

Blueprint үлгісінде `LLM_MODE=demo` әдепкі мәні сақталған. **Blueprint Manual sync** кейін ол қайта орнатылуы мүмкін; ЖИ-ді қосқаннан кейін код жаңартуға веб-сервистегі **Manual Deploy** қолданыңыз. Қажет болса өз Blueprint конфигурацияңызды да live режиміне сәйкестендіріңіз, бірақ кілтті YAML-ға жазбаңыз.

ChatGPT жазылымы API шығынын қамтымайды. Әдепкі ортақ лимит — аккаунтқа 24 сағатта 10 генерация, серверге 100 live генерация; ойындар мен сабақтар бір лимитті пайдаланады. Бір генерацияда ең көбі екі модель шақыруы болады: бастапқы жауап және бір түзету. Бір шақыруға 12 000 output token шегі бар. Бұл ақшадағы қатаң лимит емес; провайдер аккаунтында да шығынды бақылаңыз.

## Жүктелетін файлдар

- **Материал** — UTF-8 Markdown (`.md`): түсіндірме, мақсаттар, сөздік, үй тапсырмасы. Жауап кілті бұл файлға қосылмайды.
- **Презентация** — өңдеуге болатын PowerPoint (`.pptx`), әр слайдта баяндамашының жазбалары бар. Аккаунт иесіне ғана қолжетімді; қосымша ЖИ сұранысын жасамайды.
- **Оқу видеосы** — браузерде слайдтардан жасалатын дыбыссыз ролик, әр слайдқа 8 секунд. Chrome/Edge әдетте WebM жүктейді; MP4 тек браузер оны қолдаса қолданылады. Жасалу уақыты ролик ұзақтығына жақын. Бетті ашық ұстаңыз; басқа бетке өтсеңіз жазу тоқтайды. Бас тартуға болады. Камера, микрофон және ақылы видео API қолданылмайды.

Файл жүктеу әзірге web нұсқасында бар; native қосымшада сабақты оқып, ойынды ашуға болады. Дауыс, ЖИ жасаған бейнелер, анимацияланған кейіпкерлер және кинематографиялық видео осы нұсқаға кірмейді; бұларға бөлек генерация/дыбыстау қызметі мен фондық өңдеу керек.

## Мазмұн сапасы мен тексеру

ЖИ материалды өзінің білімінен құрастырады; интернеттен дерек іздеу немесе оқулықпен сәйкестігін растау орындалмайды. Сервер құрылымды, параметрлерді, жауап сілтемелерін, бірегей ID-лерді және тапсырма дәлелінің жасалған мәтінде барын тексереді. Фактінің шын екенін және сабақ сапасын мұғалім тексереді. Нақты модельмен алғашқы іске қосуда қазақша және орысша фактілерді, есеп жауаптарын, сыныпқа сәйкестігін, уақыт пен шығынды бағалаңыз.

Демо режимі өз тақырыбыңызға жалған дайын жауап бермейді: нақты ЖИ қосу туралы хабар көрсетеді. Қате болса енгізілген тақырып сол экранда қалады. Бетті толық жаңартқанда сақталмаған форма жоғалады; сәтті жасалған сабақтар базада сақталады.

Автоматты тексерулер басқарылатын провайдер жауаптарымен орындалады; бұл ортаға нақты API кілті берілмегендіктен ақылы модель шақырылған жоқ.
