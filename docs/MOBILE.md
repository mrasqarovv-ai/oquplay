# Android және iPhone

## Не тексерілді?

Expo SDK 57 үшін тәуелділіктер үйлесімділігі тексерілді. iOS және Android JavaScript/Hermes жинақтары экспортталды. Бұл `.apk`/`.ipa` құрастыру немесе нақты телефонда тексеру емес. Бұл ортада Xcode, Android emulator және физикалық телефон болмады.

## Компьютер мен телефонды байланыстыру

1. Компьютерде README бойынша пакеттерді орнатып, базаны және API-ді іске қосыңыз.
2. Компьютер мен телефонды бір Wi-Fi желісіне қосыңыз.
3. Windows-та `ipconfig` командасынан белсенді Wi-Fi-дың IPv4 мекенжайын табыңыз. Мысал: `192.168.1.10`. Mac-та System Settings → Wi-Fi → Details → TCP/IP ішінен көріңіз.
4. **`apps/mobile/.env`** ішінде:

```dotenv
EXPO_PUBLIC_API_URL=http://192.168.1.10:3001
EXPO_PUBLIC_WEB_URL=http://192.168.1.10:8081
```

Мысалдағы IP-ді өз компьютеріңіздікіне ауыстырыңыз. API — 3001, Expo web — 8081. `EXPO_PUBLIC_*` мәндері қосымшаға ашық енгізіледі, сондықтан мұнда кілт пен құпиясөз жазылмайды.

5. **`apps/api/.env`** ішінде `HOST=0.0.0.0` болсын. Телефон браузерінде Expo web-ты қолдансаңыз, `WEB_ORIGIN=http://192.168.1.10:8081` етіп өзгертіңіз. Origin-де артық `/` болмасын. Native Expo қолданбасы cookie origin-ге тәуелді емес, bearer сессиясын қолданады.
6. Бірінші терминалда, **oquplay түбірінде**:

```bash
npm run dev:api
```

7. Екінші терминалда, **oquplay түбірінде**:

```bash
npm run dev:mobile
```

Expo QR көрсетеді. iPhone-да камерамен, Android-та Expo Go арқылы ашыңыз. Орнатылған Expo Go SDK 57-ні қолдауы керек. Қолдамаса, сәйкес development build қолданыңыз; пакет нұсқаларын өз бетіңізше `latest`-ке ауыстырмаңыз.

`.env` өзгерген соң Expo-ны тоқтатып, қайта қосыңыз; қажет болса **apps/mobile қалтасында** `npx expo start --clear` орындаңыз.

## Мекенжайлар

| Қай жерден қосыласыз | API мекенжайы |
| --- | --- |
| Компьютер браузері | `http://localhost:3001` |
| Android Studio стандартты эмуляторы | `http://10.0.2.2:3001` |
| Mac-тағы iOS Simulator | `http://localhost:3001` |
| Нақты Android немесе iPhone | `http://КОМПЬЮТЕР_IP:3001` |
| Орналастырылған release қосымшасы | `https://СЕРВЕР_ДОМЕНІ` |

Нақты телефондағы `localhost` компьютерді білдірмейді. Компьютердің firewall-ы жеке Wi-Fi желісінде Node/3001 және Expo/8081 қосылуларына рұқсат беруі керек. Мектеп Wi-Fi-ындағы client isolation құрылғылардың өзара қосылуын бұғаттауы мүмкін. Expo tunnel қолдану backend-ті автоматты түрде сыртқа ашпайды.

Жергілікті HTTP — әзірлеу ортасы үшін. Native release/development build-тің желі саясаты HTTP-ді шектеуі мүмкін; тұрақты телефон тесті мен release үшін HTTPS backend пайдаланыңыз. Production-да HTTP-ді бәріне рұқсат етуге арналған кең ATS/Android network bypass енгізілген жоқ.

## Екі платформада қолмен қабылдау тізімі

Әр пунктті Android және iPhone-да жеке белгілеңіз:

- Тіркелу, шығу, қайта кіру; қолданбаны жауып ашқанда сессияның сақталуы.
- Қазақ әріптері: ә, ғ, қ, ң, ө, ұ, ү, һ, і; орысша ауысу.
- Пернетақта ашылғанда соңғы өрістер мен әрекет батырмаларына жету.
- Safe area: ойық/камера және төменгі gesture жолы мәтінді жаппайды.
- Үш демо ойынды жасау, түзету, жеке орындау; teacher жариялауы.
- Викторина жауабының таңдалуы және түсіндірмелер.
- Matching екі бағаны, жұпты ауыстыру, 320–390 px экраны.
- Ordering жоғары/төмен батырмалары; drag міндетті емес.
- Уақытпен ойын, фонға кетіп қайта келу, автоматты submit.
- Желі үзілісі, сервер қатесі, қате/жабылған код, деректердің сақталуы.
- Нәтижеден retry: бір қатысушы, екі әрекет.
- VoiceOver/TalkBack: өріс атаулары, radio/checkbox күйі, батырмалар.
- Web сілтемені Safari/Chrome-да қосымша орнатпай ашу.

`oquplay://join?code=...` scheme Expo конфигурациясында бар. HTTPS universal/app links үшін доменді растау (AASA/assetlinks) әлі бапталмаған. Сондықтан бөлісудің негізгі жолы — web URL немесе код.
