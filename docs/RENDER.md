# Запуск OquPlay через Render

Исходный код опубликован на GitHub. Эта кнопка открывает создание сайта и базы данных в вашем аккаунте Render:

[**Запустить OquPlay**](https://render.com/deploy?repo=https://github.com/mrasqarovv-ai/oquplay)

1. Откройте кнопку и войдите в Render через GitHub. Если аккаунта нет, зарегистрируйтесь.
2. Разрешите Render читать репозиторий `mrasqarovv-ai/oquplay`. В форме запуска проверьте, что для сайта и базы выбран тариф **Free**. Подтвердите создание кнопкой **Deploy** или **Create resources**.
3. Дождитесь статуса **Live** у веб-сервиса `oquplay`. Откройте указанный на его странице адрес `https://…onrender.com` — это ссылка на ваш сайт. Создайте свой аккаунт внутри OquPlay.

При первом запуске Render собирает интерфейс, создаёт таблицы в базе и запускает сервер. Вводить команды или ключ ИИ не требуется. Конфигурация находится в [render.yaml](../render.yaml).

Для этого размещения переменная `EXPO_PUBLIC_API_URL` в Render не нужна: сайт обращается к API на своём адресе. Если она уже добавлена и содержит случайную строку вместо URL, удалите эту строку в **Environment → Edit**, затем выберите **Save, rebuild, and deploy**. Адрес API встраивается при сборке, поэтому требуется пересборка интерфейса. Текущий шаблон также явно задаёт пустое значение в команде web-сборки.

## Ограничения бесплатного запуска

Это вариант для знакомства с приложением. Бесплатный веб-сервис засыпает после простоя, поэтому первое открытие может быть медленным. По условиям бесплатного Render PostgreSQL база действует **30 дней**, после чего требуется перейти на платный тариф; без этого база и данные будут удалены по правилам Render. Проверьте актуальные условия и стоимость в панели перед созданием ресурсов: [Free instances](https://render.com/docs/free), [тарифы](https://render.com/pricing).

Для постоянного использования заранее выберите подходящий тариф базы, настройте резервные копии и проверьте восстановление. Сам шаблон не включает платные ресурсы. Если Free недоступен в вашем аккаунте, не подтверждайте платный тариф без проверки стоимости.

OquPlay запускается в **деморежиме**: можно зарегистрироваться, загрузить готовый образец, создать игру и поделиться кодом. Генерация заданий по произвольному тексту требует отдельного подключения платного провайдера ИИ; ключ вводится только в защищённые переменные сервера.

Для нового сценария «тема → материал → задания → презентация» откройте **ИИ студию уроков**. Подключение реального ИИ и обновление уже работающего Render-сервиса описаны в [AI_LESSONS.md](AI_LESSONS.md). Без подключения провайдера студия не подменяет вашу тему готовым демо.

## Что шаблон настраивает

- Node.js 24, один веб-сервис и PostgreSQL 17 в одном регионе.
- Сайт и API на одном HTTPS-адресе; адрес Render используется для проверки Origin и защищённых cookie.
- Внутреннее соединение с базой без ручного копирования пароля; публичный доступ к базе закрыт.
- Миграции перед запуском и проверку `/api/health`, которая также проверяет соединение с базой.
- Ручное обновление сайта: после новых коммитов выберите **Manual Deploy → Deploy latest commit**. Автоматическое развёртывание выключено.

Если добавляете свой домен, измените `WEB_ORIGIN` в команде запуска на полный HTTPS-адрес домена и проверьте вход и публикацию заново. По умолчанию команда использует встроенную переменную `RENDER_EXTERNAL_URL`.

Перед использованием в классе учтите раздел о proxy и масштабировании в [DEPLOYMENT.md](DEPLOYMENT.md): сервер пока применяет ограничения запросов к IP соединения с proxy. Этот шаблон рассчитан на небольшое демо с одним процессом.

Из облачной среды разработки нельзя создать ресурсы в вашем аккаунте без подключения Render. Наличие шаблона на GitHub не означает, что сайт уже работает: фактический запуск и публичный HTTPS-адрес проверяются после создания ресурсов в Render.
