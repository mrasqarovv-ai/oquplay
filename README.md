# OquPlay AI · алғашқы жұмыс нұсқасы

**Открыть как сайт:** [запустить через Render](https://render.com/deploy?repo=https://github.com/mrasqarovv-ai/oquplay) · [простая инструкция на русском](docs/RENDER.md). Нужен аккаунт Render. Бесплатная база действует 30 дней; для постоянной работы потребуется выбрать тариф. Кнопка создаёт сайт после подтверждения в Render.

Оқу мәтінінен викторина, сәйкестендіру және реттілік тапсырмаларын жасауға арналған **React Native + Expo** қосымшасы. Android, iOS және web бір интерфейс кодын пайдаланады. Fastify сервері аккаунттарды, ЖИ сұраныстарын, қолжетімділікті және ұпайларды басқарады. PostgreSQL деректерді сақтайды.

Бұл архив — бастапқы код. Ол iPhone-ға тікелей орнатылатын `.ipa` немесе Android `.apk` файлы емес. Алғашқы іске қосу үшін компьютер қажет. Жалпыға жариялау және ақылы ЖИ қызметін қосу орындалған жоқ.

## 1. Алдымен не орнату керек?

- Node.js **24 LTS** және онымен бірге npm.
- Docker Desktop, іске қосулы күйде. Ол тек жергілікті PostgreSQL үшін керек. Бар PostgreSQL қолдансаңыз, Docker міндетті емес.
- Кодты ашуға VS Code ыңғайлы; міндетті емес.
- Телефонда тексеру үшін Expo Go немесе development build. Нақты SDK сәйкестігін `docs/MOBILE.md` бөлімінен қараңыз.

Архивті ашып, `oquplay` қалтасын табыңыз. Осы қалтада `package.json`, `apps` және `README.md` тұрады. Төмендегі командалардың бәрін **осы түбір қалтадағы терминалда** орындаңыз, өзгеше көрсетілмесе.

## 2. API кілтінсіз алғашқы іске қосу

Командаларды бір-бірден орындаңыз:

```bash
npm ci
npm run setup:env
docker compose up -d db
npm run db:generate
npm run db:migrate
npm run build:web
npm run preview
```

| Команда | Күтілетін нәтиже |
| --- | --- |
| `npm ci` | Нұсқалары `package-lock.json` арқылы бекітілген пакеттер орнатылады. |
| `npm run setup:env` | `apps/api/.env` және `apps/mobile/.env` жасалады. Бар файлдар өзгермейді. |
| `docker compose up -d db` | Компьютеріңіздегі PostgreSQL қосылады. Бірінші рет image жүктеледі. |
| `npm run db:generate` | Prisma типтері мен клиенті жасалады. |
| `npm run db:migrate` | Деректер базасына кестелер, индекстер және байланыстар қосылады. |
| `npm run build:web` | Expo web нұсқасы `apps/mobile/dist` ішіне жиналады. |
| `npm run preview` | Сервер және жиналған web бір мекенжайда ашылады. |

Браузерде **http://localhost:3001** ашыңыз. Соңғы команданың терминалын жаппаңыз. Тоқтату: `Ctrl+C`. Кейін қайта қосу: `docker compose up -d db`, одан соң `npm run preview`.

Алдын ала орнатылған ортақ аккаунт жоқ. Өз аккаунтыңызды интерфейсте жасаңыз. Email бұл нұсқада тек логин ретінде қолданылады, хат жіберілмейді.

`local_only` — тек компьютердегі демо базаға арналған мысал пароль. Оны сыртқы серверде қолданбаңыз. Docker базасы әдепкіде тек `127.0.0.1` арқылы ашылады.

## 3. Алғашқы ойынның толық жолы

1. «Мұғаліммін» → пошта, атыңыз және кемінде 10 таңбалы құпиясөз → «Тіркелу».
2. «Жаңа ойын жасау» → «Дайын үлгіні жүктеу».
3. «Жалғастыру» → үш ойынның бірін таңдаңыз → «Тапсырмалар құрастыру».
4. Сұрақтарды, жауаптарды, түсіндірмелер мен дәлел үзінділерін тексеріңіз. Редакторда қосу, өшіру, ауыстыру және бір тапсырманы қайта құрастыру бар.
5. «Алдын ала көру» арқылы ойынды тексеріңіз. Бұл қарау сынып нәтижесіне есептелмейді.
6. «Сақтау» → тексерілгенін растайтын құсбелгі → «Жариялау».
7. 16 таңбалы кодты көшіріңіз. Басқа браузерде не жеке терезеде «Кодпен қосылу» арқылы оқушы ретінде кіріңіз.
8. Ойынды аяқтаңыз. Мұғалім терезесінде «Сынып нәтижелері» бөлімін ашыңыз.

**Демо режимінде дайын 5 тапсырмалық тарихи үлгі ғана қолданылады.** Өз мәтініңізге сай тапсырма жасалды деген жалған әсер берілмейді. Демо белгісі редакторда, ойында және нәтижеде көрінеді. Қазақша және орысша үлгілер бар.

Оқушы аккаунты дәл осы конструкторды пайдаланады, бірақ оның жаттығулары жеке қалады; жариялау операциясы серверде де жабық.

## 4. Кодты өзгерте отырып жұмыс істеу

`npm run preview`-ді тоқтатыңыз. Екі терминалды да **oquplay түбір қалтасында** ашыңыз:

Бірінші терминал:

```bash
npm run dev:api
```

Екінші терминал:

```bash
npm run dev:web
```

API — `http://localhost:3001`, Expo web — `http://localhost:8081`. `apps/api/.env` ішіндегі `WEB_ORIGIN=http://localhost:8081` болсын. Preview командасы өз процесі үшін origin-ді автоматты ауыстырады; файлды өзгертпейді.

Бір компьютерде `localhost` және `127.0.0.1` атауларын араластырмай, нұсқаулықтағы бір атауды пайдаланыңыз: cookie мен origin соған байланысты.

## 5. Нақты ЖИ-ді кейін қосу

Тек **`apps/api/.env`** файлын өзгертіңіз:

```dotenv
LLM_MODE=live
LLM_API_KEY=
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=
```

Кілтті сервер ортасына өзіңіз енгізіңіз; чатқа жібермеңіз. `LLM_MODEL` орнына OpenAI панелінде қолжетімді, **Responses API + Structured Outputs** қолдайтын модельдің нақты ID-ін жазыңыз. Модельдің қолжетімділігі мен тарифін сол провайдерден тексеріңіз. Екі өріс толмайынша live сервер іске қосылмайды.

Серверді қайта іске қосыңыз. «ЖИ қосулы» белгісі көрінеді. Енді өз мәтініңіз бен пән/сынып/A–B–C/5–10–15 параметрлері қолданылады. Бір сұранысқа ең көбі екі провайдер шақыруы болады: бастапқы жауап және қажет болса бір түзету. Әдепкі шектеу — аккаунтқа 10 генерация/24 сағат, серверге 100 live генерация/24 сағат, әр шақыруға 12 000 output token. Бұл ақшалай бюджет емес; провайдер жағында да бюджет шегін орнатыңыз.

**Нақты ақылы API шақыруы осы жеткізілімде тексерілген жоқ:** кілт берілмеген. HTTP адаптері, қате жауаптар, схема тексеруі және түзету шегі басқарылатын тест жауаптарымен тексеріледі. Басқа провайдер үшін `LLMProvider` интерфейсінің жеке адаптерін жазу керек; тек base URL-ді ауыстыру үйлесімділікке кепіл емес.

## 6. Телефонда іске қосу

Толық нұсқаулық: [docs/MOBILE.md](docs/MOBILE.md). Маңыздысы: **телефондағы `localhost` — телефонның өзі**, сіздің компьютеріңіз емес. Телефон мен компьютер бір Wi-Fi желісінде болып, `EXPO_PUBLIC_API_URL` компьютердің LAN IP мекенжайын көрсетуі керек.

## 7. Жоба құрылымы

| Қалта/файл | Мақсаты |
| --- | --- |
| `apps/mobile/app` | Expo Router экрандары. |
| `apps/mobile/src` | API клиенті, SecureStore, интерфейс, редактор, үш ойын механикасы. |
| `apps/api/src` | Fastify API, қолжетімділік, ұпай, ЖИ адаптері және промт. |
| `apps/api/prisma` | PostgreSQL схемасы және SQL миграциясы. |
| `packages/shared/src` | Zod схемалары, типтер, демо материал, екі тілдің интерфейс мәтіндері. |
| `tests/e2e` | Браузердегі толық сценарийлер. |
| `brand.json` | Қосымша атауын өзгертетін ортақ файл. |
| `docs` | Архитектура, тест нәтижелері, deployment және шектеулер. |
